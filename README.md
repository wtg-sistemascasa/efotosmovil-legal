# efotosmovil-legal

Términos y condiciones de e-FotosMovil de Sistemas CASA S.A. de C.V.

## Publicación

El sitio está en `index.html`, sin dependencias ni proceso de compilación.
En Settings > Pages, seleccionar "Deploy from a branch", rama `main` y carpeta
`/ (root)`. No escribir la dirección de GitHub Pages en "Custom domain".

Dirección prevista: https://wtg-sistemascasa.github.io/efotosmovil-legal/
